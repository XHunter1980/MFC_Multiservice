## 1. Подготовка и формат файла Excel

Для работы утилиты требуется файл Excel (`.xlsx` или `.xls`) со списком устройств. Файл **обязательно** должен содержать следующие колонки (названия должны совпадать точно):

| Колонка | Описание | Пример |
|---------|----------|--------|
| `IP` | IP-адрес устройства | `192.168.1.10` |
| `Login` | Имя пользователя для SSH | `admin` |
| `Password` | Пароль для SSH | `MySecurePass123` |
| `ENABLE` | Флаг активности (`+`, `Y`, `YES`, `TRUE`, `1`) | `+` |
| `NAME` | Имя или идентификатор устройства | `Device_Floor_1` |
| `ARH` | Архитектура устройства (важно для проверки совместимости) | `x86_64` или `arm` |
| `Model` | Модель устройства (например, `ALT_SP` для особой обработки) | `ALT_SP` |

> **Совет:** При загрузке файла откроется диалоговое окно, где можно снять галочки с устройств, которые не должны участвовать в текущей операции.

## 2. Первый запуск и интерфейс

При первом запуске создается файл `updater_settings.json`, который запоминает ваши последние пути и настройки. Интерфейс состоит из нескольких вкладок и общей панели прогресса с цветным журналом событий внизу.

---

## 3. Вкладка "Обновление"

Предназначена для массового обновления ПО и конфигураций.

1. **Список устройств**: Выберите файл Excel и нажмите "Выбрать".
2. **Выбор обновлений**: Отметьте галочками нужные типы обновлений:
   - *Прошивка*: Требует указания директории, содержащей файлы `.img`, `RemoteInstallServer` и `update.stu`.
   - *Конфигурация*: Требует выбора файла `.xml`. Утилита сравнит описание и размер файла с устройством и обновит его только при различиях.
   - *Target2*: Требует выбора файла `target2.xml`.
3. **Действия**:
   - **Выполнить обновления**: Запускает процесс.
   - **Перезагрузить**: Перезагружает выбранные устройства после обновления (если включено в настройках).
   - **Остановить**: Безопасно прерывает текущую операцию.

---

## 4. Вкладка "Операции"

Инструменты для аудита и обслуживания устройств.

- **Проверить устройства**: Быстрый ping/SSH-чек доступности всех выбранных устройств.
- **Проверить прошивки / конфиги**: Сравнивает версии на устройствах с локальными эталонными файлами.
- **Собрать информацию**: Подключается к устройствам и собирает данные об ОС, версии ПО, конфигурации и MAC-адресах. Результат сохраняется в файл `device_info_ГГГГММДД_ЧЧММСС.xlsx`.
- **Проверить дубликаты MAC**: Анализирует собранные данные и формирует отчет `mac_duplicates_report_...xlsx`, если один MAC-адрес встречается на разных устройствах.
- **Загрузка файлов на устройства**:
  1. Укажите локальную директорию с файлами.
  2. Укажите удаленный путь (например, `/tmp/` или `/home/user/`).
  3. Нажмите "Загрузить". Утилита автоматически создаст нужные папки, переименует старые файлы (добавив суффикс `.old_дата_время`), загрузит новые и проверит их целостность по размеру.

## 5. Вкладка "Команды"

Позволяет выполнять произвольные действия на устройствах.

- **Консольная команда**: Введите команду (например, `df -h` или `systemctl status`). История команд сохраняется.
- **Суперпользователь**: Если устройству требуются права root (особенно актуально для `ALT_SP`), установите эту галочку и введите пароль SU. Утилита автоматически выполнит команду `su`.
- **Послать консольную команду**: Выполняет ввод на всех выбранных устройствах.
- **Рестарт ППО**: Специализированная кнопка для безопасного перезапуска служб `PrjA-tele` и `PrjA` через `systemctl`.

---

## 6. Вкладка "Настройки"

- **Опции проверок**: Включите или отключите предварительную сверку версий прошивки и конфигурации перед обновлением.
- **Тестовый режим (Dry Run)**: **Крайне рекомендуется включать перед массовыми операциями.** В этом режиме утилита выполняет все проверки и пишет в лог, что *сделала бы*, но не выполняет реальных изменений на устройствах.
- **Вести лог**: Сохраняет журнал операций в файл (укажите директорию). Файлы логируются с ротацией (макс. 10 МБ, хранится 3 последние версии).
- **Перезагружать устройства**: Автоматически перезагружать устройства после успешного обновления.

## 7. Решение частых проблем

| Проблема | Возможная причина и решение |
|----------|-----------------------------|
| **Ошибка чтения файла Excel** | Проверьте, что названия колонок в точности совпадают с требуемыми (`IP`, `Login`, `Password`, `ENABLE`, `NAME`, `ARH`, `Model`). Убедитесь, что файл не открыт в другом приложении. |
| **Предупреждение о разных архитектурах** | Вы выбрали устройства с разным значением в колонке `ARH` для обновления прошивки. Это заблокировано во избежание "окирпичивания". Отфильтруйте устройства в диалоге выбора. |
| **Таймаут подключения к ALT_SP** | Устройства ALT_SP требуют больше времени на инициализацию shell и ввод `su`. Утилита автоматически увеличивает таймаут до 30 секунд для таких устройств. Проверьте корректность пароля SU. |
| **Не обновляется конфигурация** | Если включена проверка, утилита пропускает обновление, если описание (`<Global description="...">`) и размер файла совпадают с локальным. Это штатное поведение для экономии времени. |
| **Операция "зависла"** | Нажмите кнопку "Остановить". Утилита корректно закроет активные SSH-соединения и прервет цикл. |
